# Ejercicio nº 1 - Empresa de vuelos

Una compañía de vuelos cuenta con N destinos a los que realiza 3 vuelos diariamente, un por la mañana otro al medio dia y otro por la noche. Para administrar estos datos, utiliza una matriz donde cada fila es un destino y en cada columna se guardan la cantidad de asientos disponibles.

* Se necesita un programa que permita la carga de los destinos y la cantidad de asientos para cada vuelo (Aplicando vectores y matrices)

* Al mismo tiempo, el programa debe permitir al usuario ingresar el número de destino al que quiere dirigirse, el número de vuelo (dependiendo si quiere viajar en la mañana, al medio dia o por la noche) y la cantidad de pasaje que necesita.

* A partir de la solicitud del usuario, el programa debe controlar si hay cantidad suficientes de asientos para la cantidad de pasajes que se requiere. En caso de que así sea se debe mostrar un cartel por pantalla que diga "Su reserva fue realizada con éxito" y se debe descontar del total de asientos disponibles.  se debe informar otro cartel que diga "disculpe no se pudo completar su operación dado que no hay asientos disponibles".

Nota: Desde la compañía de vuelos manifiestan que no conocen cuantas ventas/reservas se hacen por día. Por lo cual, para finalizar las ventas se ingresa la palabra "finish".
